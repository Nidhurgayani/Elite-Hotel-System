# 🏨 Elite Hotel System

## Project Overview

The **Elite Hotel System** is a web-based hotel reservation and management application developed as a university group project.

The system is designed to support hotel management activities through a user-friendly interface and API integration.

## ✨ Main Features

- User Login and Authentication
- Customer Management
- Staff Management
- Room Management
- Booking Management
- API Integration

## 🛠️ Technologies Used

- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Database:** PostgreSQL
- **API Testing:** Postman

## 🧪 API Testing

Postman was used to check API requests and responses.

The Postman collection is available in the `postman` folder.

- Customers

- Tasks

HTTP methods used in the collection include:

- GET
- POST
- PUT
- DELETE

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Nidhurgayani/Elite-Hotel-System.git
   ```

2. Open the project folder:

   ```bash
   cd Elite-Hotel-System
   ```

3. Install the frontend and backend dependencies using the relevant package manager and project instructions.

4. Configure the required environment variables and database connection locally.

5. Start the frontend and backend using their respective start scripts.

*Refer to the frontend and backend package files for the exact installation and start commands.*
